## 标题

我做了一个 GB/T 7714—2025 Zotero 文献助手

## 正文简易版

最近整理参考文献时，发现新版国标对中国作者拼音姓名和在线电子资源的处理更细了。

所以我做了一个 Zotero 9 插件：**国标 2025 文献助手**。

目前主要解决两个问题：

1. 批量检查拼音姓名，把 `Wu | Sai Xuan` 这类姓名预览并保存为单字段 `Wu Saixuan`，避免参考文献只显示名字缩写。
2. 批量标记在线电子资源，在 Extra 中写入 `Medium: OL`，同时规范 DOI 和网址。DOI 优先，没有 DOI 才显示 URL。

使用方法很简单：

选择一篇或多篇文献 → 右键“GB/T 7714—2025 文献助手” → 规范化 → 预览 → 应用。

姓名和电子资源是两个独立模块，支持上百篇批量处理、全选、折叠查看和本地撤销。所有修改都要先预览确认，插件不会直接判断作者国籍。

插件免费开源，适配 Zotero 9。安装包、配套 CSL 和详细说明都放在 GitHub Releases。

## 评论区置顶简版操作说明

安装：下载 XPI → Zotero“工具 → 插件” → 右上角菜单 → “Install Plugin From File…” → 选择 XPI → 重启 Zotero。

使用：选中文献 → 右键“GB/T 7714—2025 文献助手” → “规范化…” → 检查姓名或 OL → 应用。

建议第一次先用少量测试条目，重要文献库提前备份。
