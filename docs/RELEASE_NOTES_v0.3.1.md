# 国标 2025 文献助手 v0.3.1

首个公开测试版本，适配 Zotero 9.0.x。

## 主要功能

- 批量识别和预览可能需要规范化的中国作者拼音姓名。
- 按文献折叠责任者，将确认后的姓名保存为 `Wu Saixuan` 式单字段姓名。
- 批量写入权威电子资源标记 `Medium: OL`。
- 规范 DOI，参考文献优先输出 DOI 链接，没有 DOI 时使用 URL。
- 可选清空整个 Extra 后写入 OL。
- 保存本地修改快照，提供冲突安全的整批撤销。
- 提供 Zotero 专用的 GB/T 7714—2025 顺序编码双语 CSL。

## v0.3.1 界面改进

- 右键入口明确显示“GB/T 7714—2025 文献助手”。
- 姓名规范化和电子资源（OL）改为两个独立功能模块。
- 列表增加固定表头和网格结构。
- 修复大量文献时无法滚动、底部按钮不可见的问题。
- 已使用 120 篇文献、360 个姓名候选完成界面压力测试。

## 安装

1. 下载 `gbt7714-2025-helper-0.3.1.xpi`。
2. 在 Zotero 中进入“工具 → 插件”。
3. 点击“Tools for all plugins → Install Plugin From File…”。
4. 选择 XPI 并重启 Zotero。

不要通过 Zotero 的文献“导入”功能安装 XPI。
