# 简易操作说明

## 一、安装插件

1. 在 GitHub Releases 下载最新版 `.xpi` 文件。
2. 打开 Zotero，进入“工具 → 插件”。
3. 点击右上角“Tools for all plugins”按钮。
4. 选择“Install Plugin From File…”。
5. 选择下载的 XPI，安装后重启 Zotero。

注意：不要通过 Zotero 的“导入”功能安装 XPI。

## 二、修改拼音姓名

1. 在条目列表选择一篇或多篇文献。
2. 右键选择“GB/T 7714—2025 文献助手 → 规范化…”。
3. 打开“姓名规范化”模块。
4. 按文献展开作者，检查目标姓名。
5. 勾选需要修改的姓名，点击“应用所选更改”。

示例：`Wu | Sai Xuan` 会保存为单字段姓名 `Wu Saixuan`。

插件只提供可能需要处理的姓名候选，不判断作者国籍。低置信度候选默认不勾选，请人工确认。

## 三、标记电子资源

1. 打开“电子资源（OL）”模块。
2. 勾选需要标记为在线资源的条目。
3. 检查 DOI 和网址。
4. 确认后点击“应用所选更改”。

插件会在 Extra 中写入：

```text
Medium: OL
```

有 DOI 时参考文献优先输出 DOI 链接；没有 DOI 时才输出网址。没有 DOI 或网址的条目不能确认 OL。

“清空整个 Extra 后写入 OL”会删除 Extra 中的其他内容，只有确实需要时再勾选。

## 四、撤销修改

在条目列表右键选择：

- “撤销上一次修改…”：撤销最近一批修改。
- “修改记录与撤销…”：查看历史批次并选择撤销。

撤销快照保存在 Zotero 本地数据目录。若条目之后又被人工修改，插件会提示冲突并默认跳过，避免覆盖新数据。

## 五、使用建议

- 第一次使用时先选择少量测试条目。
- 应用前检查姓名、DOI、网址和 Extra。
- 重要文献库建议同时保留 Zotero 数据备份。
- 配套 CSL 需要单独安装，插件不会覆盖已有样式。
